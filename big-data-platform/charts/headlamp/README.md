# 📦 Headlamp Sub-chart

A modern, extensible Kubernetes web UI for cluster management and observability.

## 🚀 Overview
- **Role**: Operator-friendly dashboard for managing platform resources.
- **Image**: `headlamp/headlamp:latest`.
- **Sync Wave**: `0` (Application Layer).

## 🔑 Access
Authentication is handled via ServiceAccount tokens. See the root README for instructions on generating an admin token.

## 🛠 Configuration
```yaml
headlamp:
  enabled: true
```
